## 👋 About me

I build practical software with a strong focus on **structure, simplicity and real-world usability**.
Before I wrote code, I wired buildings – first as a certified electrician, today as a junior project manager in electrical engineering.
That background shaped how I work: **plan carefully, build cleanly, document everything, and make sure it actually works in the field.**

If I see a problem, I enjoy finding a clean and efficient way to solve it – and turning the idea into a working application.
